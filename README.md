# 🎬 URGIMCHAK TAXI — PREMIUM ANIMATION & MOTION DESIGN SYSTEM

Ushbu loyiha **O'rgimchak Taxi** brendi uchun **React 18 + TypeScript + Vite + Framer Motion + Lucide Icons** texnologiyalari asosida yaratilgan premium, kinematografik va yuqori darajada optimallashtirilgan Landing Page hisoblanadi.

---

## 🌟 Motion & Dizayn Xususiyatlari

- 🎬 **Ketma-ket Kinematik Entrance (Hero)**: Navbar → Sarlavha → Tavsif → CTA → Taxi Vizual → Suzuvchi UI Kartochkalar.
- ⚡ **Sariq Nurli Tezlik Traektoriyasi (Light Trail)**: Hero orqa fonida doimiy va silliq harakatlanuvchi sariq nur izlari.
- 🎯 **3D Sichqoncha Parallaksi (Mouse Parallax)**: Desktopda kursor harakatiga juda muloyim va nozik javob beruvchi 3D effektlar.
- 🔢 **Jonli Hisoblagichlar (Animated Stats Counter)**: Viewportga kirganda 0 dan maqsadli qiymatgacha silliq oshuvchi raqamlar (500K+, 3 Min, 12 Viloyat, 99.4%).
- 🛣️ **Qadamlar Xronologiyasi (How It Works)**: Scroll davomida animatsiya bilan to'luvchi progress chizig'i va interaktiv bosqichlar.
- 🗺️ **O'zbekiston Qamrovi (Interactive Map)**: Pulsatsiyalanuvchi nuqtalar, real vaqtda yo'ldagi mashinalar va viloyatlararo marshrutlar.
- 🛡️ **Xavfsizlik va Telemetriya**: Animatsiyali xavfsizlik nishonlari va 24/7 jonli SOS tizimi.
- 💼 **Haydovchilar Daromad Kalkulyatori**: Kunlik va haftalik ish soatlariga qarab real daromadni hisoblab beruvchi interaktiv kalkulyator.
- 📱 **3D Suzuvchi Smartfon Mockup**: 4-6 soniyalik davriy suzuvchi smartfon va ilova ekrani.
- ❓ **FAQ Akkordeon**: Silliq ochilib-yopiluvchi savol-javoblar va toifalar bo'yicha saralash.
- 🔍 **SEO & Structured Data**: OpenGraph, Twitter Cards, Semantik teglar va `Schema.org TaxiService` JSON-LD to'liq integratsiya qilingan.
